# Opportunity Radar — working notes for Claude Code

- Product/decision context: README.md, docs/STRATEGY.md, docs/DECISIONS.md, docs/STATUS.md.
- Stack: Next.js 16 App Router, SQLite via libSQL (@libsql/client, async; Turso in the cloud) + Drizzle (migrations in `drizzle/`, regenerate with `pnpm exec drizzle-kit generate --name <x>`), Zod 4, Anthropic SDK structured outputs, Tailwind 4.
- Run: `pnpm dev` (embedded worker). Tests: `pnpm test` (Vitest), `pnpm test:e2e` (Playwright; builds + serves on :3100, uses data/e2e.db).
- Live checks without AI: `DATABASE_PATH=./data/dev.db pnpm exec tsx scripts/live-check.ts` and `scripts/research-some.ts "<business name>"`. Do not deploy to Vercel unless the founder asks (they declined on 2026-10-27).
- Flow v2: one `investigate_business` job per business → structured profile facts (`src/lib/profile/fields.ts`; verified with quote / not_found / unknown) → opportunities cite fact keys → verdict (opportunity | no_opportunity | needs_ai). Rules: AI facts are rejected unless the quote is verbatim in the cited page; detected facts are authoritative; no outreach sending; demo data labeled, deterministic ids, `.example` domains; website text is untrusted.
- Research engine v3 (docs/RESEARCH.md): lead score + chain detection (`src/lib/scoring/lead.ts`) → website finder with phone/name verification (`src/lib/discovery/find-website.ts`, Brave key optional) → Firecrawl crawl (`src/lib/research/firecrawl.ts` client, `crawl.ts` orchestration, `stored.ts` reuse; FIRECRAWL_API_KEY required, 1 credit/page, monthly budget guard) ‖ off-site footprint (`src/lib/research/footprint.ts`) → deterministic facts (`detect.ts`) → rules (`src/lib/scoring/rules.ts`) + optional model → score/rank. Live scripts: `scripts/research-all.ts`, `scripts/find-websites-live.ts` (stop `pnpm dev` first or run it with `EMBEDDED_WORKER=false`, otherwise two workers compete for jobs).
- Discovery (docs/SEARCH.md): `src/lib/discovery/engine.ts` orchestrates providers (registry in `discovery/index.ts`; future/disabled ones are refused before any call). Only active source (D25): Google Maps via SerpApi (`google-maps.ts`; `SERPAPI_API_KEY`, monthly budget in `provider_usage`, pages cached in `provider_cache`, map position from the bundled place list, no geocoder). Overture (`overture.ts`) and OpenStreetMap (`osm.ts`) are `disabled` but kept (0.2° grid cells in `source_places`/`source_cells`, `area.ts` geocoding, `taxonomy.ts`). Then merge with confidence → `search_candidates` → saved businesses. Live check: `scripts/search-live.ts`. Geo data: `scripts/build-geo-data.ts`. Model providers: `src/lib/ai/providers/*` behind `callStructured` (AI_PROVIDER / keys). Lists use `src/lib/table.ts` + `src/components/table.tsx`. Audit and target architecture: docs/AUDIT.md.
- Do not run paid AI calls without the founder's explicit approval (ANTHROPIC_API_KEY, spend guard `AI_SPEND_LIMIT_USD`). Never commit, push or deploy without the founder's explicit approval.
